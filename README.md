A dog's one-line excuse after being caught eating the homework — the dog believes it gave the homework a proper burial. The entry:

> I didn't eat it — I gave it a proper burial, and my stomach is the family plot.

## Run it

```sh
node main.ts
```

`main.ts` writes the excuse to `ENTRY_OUTPUT` or `/output/entry.txt` — exactly one line, 79 characters, no trailing newline.
